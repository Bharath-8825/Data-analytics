# Excel Assignment 2

This assignment focuses on logical functions, conditional calculations, and lookup techniques using employee data.

## Topics Covered
- IF Function
- AND and OR Functions
- Nested IF Statements
- YEAR Function
- Conditional Bonus Calculations
- Employee Eligibility
- VLOOKUP Function
- INDEX and MATCH Functions
- MAX and MIN Salary Lookup
- Named Ranges
- IFERROR Function
