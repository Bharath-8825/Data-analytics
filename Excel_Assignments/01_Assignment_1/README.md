# Excel Assignment 1

This assignment focuses on basic Excel calculations and data analysis using employee salary data.

## Topics Covered
- HRA and Annual Bonus Calculations
- Gross Salary and Net Salary
- Professional Tax Calculation
- SUM Function
- AVERAGE Function
- MEDIAN Function
- MAX and MIN Functions
- COUNTA and COUNTIF Functions
- SUMIFS and AVERAGEIFS Functions
- Named Ranges
- Basic Data Analysis
